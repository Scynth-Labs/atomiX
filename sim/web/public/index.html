What you are actually looking at

    

      This is not a recording or a re-implementation. The RTL was compiled by
      Verilator into C++ and then to WebAssembly, and it is clocked here one
      cycle at a time by the same runner code the repository's
      make sim checks use. The cycle counter above is the machine's
      own count, so a number read off this page is the number a local run
      reports.
    

    

      Run role twice. It reports irq=1 and then
      irq=2, because this is one continuous machine rather than a
      fresh boot per command — the accelerator's completion interrupt is
      arriving through the SoC's PLIC. Reboot is a real power cycle,
      and the count starts over.
    

    

    

      One machine is one selection. To see what that selection is worth, the
      side-by-side page boots the same binary on
      three cores at once and puts their cycle counts next to each other.
